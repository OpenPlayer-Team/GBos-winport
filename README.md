# DietTracker

Un'applicazione Android per tenere traccia delle calorie assunte durante la giornata, costruita con HTML5 e Cordova.

Caratteristiche:
- Aggiunta pasti con relative calorie.
- Visualizzazione lista pasti.
- Calcolo totale calorie giornaliere.
- Consigli personalizzati basati sull'apporto calorico.
- Salvataggio locale persistente.

L'APK compilato si trova in `diettracker/platforms/android/app/build/outputs/apk/debug/app-debug.apk`.

Per compilare manualmente:
```bash
cd diettracker
cordova build android
```
